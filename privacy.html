Privacy policy

Effective date: 19 October 2026.

Operator and purpose

n8n Personal is operated by EDunaev for personal automation using the operator's own Google account. Contact is available through the linked GitHub profile.

Google data accessed and used

Current workflows access Gmail label information, message identifiers and label state as needed to find labels and mark selected messages as read. Marking a message as read changes its UNREAD label. The Gmail API permission granted during authorization may allow broader actions; this policy describes the workflows currently enabled.

Processing and storage

Gmail API requests are made from a self-hosted n8n installation on a Raspberry Pi. OAuth credentials are retained by that installation to maintain the authorized connection. Workflow inputs, outputs and errors may also be retained in n8n execution history, depending on the installation's execution-saving and pruning settings. Retention and any backups are controlled by the operator; this page does not specify a fixed deletion period.

Sharing and future features

The currently described Gmail workflows do not include sending message content to an AI provider or Telegram. Email reading and sending, AI processing and Telegram integration are planned. Before they are enabled, this policy will be updated to describe the actual providers, data transmitted, purposes and retention arrangements.

Limited use

n8n Personal's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements. Google user data will not be sold, used for advertising or used to train generalized AI models.

Control, revocation and deletion

The account owner can stop the workflows, disconnect the Gmail credential in n8n, and revoke the app's access in Google Account connections. Revocation stops future authorized access but does not automatically erase existing execution history or backups. The operator controls deletion of those records and credentials on the self-hosted installation.

This website

These static pages contain no analytics scripts, advertising, forms or embedded third-party resources. When hosted on GitHub Pages, GitHub handles website delivery and may process request metadata under its own privacy statement.
